## BoxCopilot v2.0.1

Wartungsrelease: Node.js-Security-Update für den Frontend-Build. Keine Breaking Changes, keine Datenbankmigrationen.

### Änderungen

- **Node.js 26.13.1** im Docker-Build (vorher floatender Tag `node:26-alpine`). Die Version enthält die Fixes des Node.js-Security-Releases vom 11.11.2026. Node wird nur beim Bauen des Frontends genutzt, das Laufzeit-Image bleibt Spring Boot.
- **CI** nutzt Node 26 statt 24 und damit dieselbe Hauptversion wie Docker-Build und lokale Entwicklung.

### Upgrade

Image neu bauen (`docker build --pull -t boxpilot .`) und Container neu starten. Es sind keine weiteren Schritte nötig.
